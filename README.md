# Симулятор торговых сигналов (Trading Signal API)

Проект выполнен в рамках учебной дисциплины. Представляет собой микросервис на базе FastAPI, имитирующий работу аналитического трейдинг-помощника.

## Стек технологий
* **Язык программирования:** Python 3.14 / 3.12
* **Фреймворк:** FastAPI (v0.110.0)
* **Сервер:** Uvicorn (v0.28.0)
* **Тестирование:** Pytest (v8.0.0)
* **Автоматизация:** GitHub Actions (CI)

## Как запустить проект локально

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

2. Запустите сервер разработки:
   ```bash
   uvicorn app_final:app --reload
   ```

## Доступные маршруты (Адреса)
* `http://127.0.0` — Проверка работоспособности сервиса.
* `http://127.0.0` — Информация о версии и авторе проекта.
* `http://127.0.0{ticker}` — Получение случайного торгового сигнала (BUY/SELL/HOLD) и актуальной цены для любого тикера (например, `btc`, `eth`, `aapl`).
* `http://127.0.0` — Интерактивная документация Swagger UI.

## Запуск автоматических тестов
Для проверки работоспособности выполните команду:
```bash
pytest
```
